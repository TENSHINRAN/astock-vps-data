隐私说明

适用应用：AStock VPS Data Uploader
维护者：TENSHINRAN · 更新日期：2026-10-17

访问的数据及用途

本工具通过 Google Drive API 上传历史市场数据 JSON、校验清单和读取说明，读取这些文件的名称、类型、大小及必要元数据，并下载文件内容核对 SHA256 和字节数。上传内容不包含 Google 客户端密钥或 OAuth 令牌。

请求范围为 drive.file。Google 的这一范围允许查看、创建、更新和删除本应用获授权的文件。当前交接脚本只执行上传、列出必要目录及下载校验，不自动删除数据。它不请求完整云盘权限，不请求 Gmail、联系人或日历权限。

保存位置及保护

历史市场文件保存在用户自己的私有 Google Drive 专用目录；传输使用 HTTPS。运行所需的客户端凭据和 OAuth 令牌仅保存在用户控制的电脑和 VPS 的受限配置目录，使用本机目录权限及 VPS 文件权限保护。配置不加入行情包，不上传到 Drive，不写入聊天正文。

本机和 VPS 可以保留必要的运行与错误记录用于排错。相关记录应保持私有，不应对外发布可能包含临时授权信息的日志。

文件读取及第三方服务

Google 提供 Drive 存储及 API 服务，VPS 和电脑由用户选择并控制。用户如另行授权 ChatGPT 等连接服务读取指定市场文件，文件将交给该服务用于用户要求的研究；这项读取由用户另行授权，适用相应服务的设置和政策。上传脚本本身不会把 OAuth 配置交给这些服务。

本上传工具不设置广告投放、数据转售或通用模型训练功能。Google API 数据仅用于上述个人文件传输、完整性校验及用户明确授权的文件读取用途。

保存期限、删除和撤销

Drive 中的市场文件由用户决定保留期限，可由用户自行删除。用户可在 Google 账号的第三方应用连接管理中撤销 AStock VPS Data Uploader 的访问，并清理自己电脑和 VPS 上的授权配置；撤销授权不会自动删除已保存的市场文件。各存储服务的回收站和备份按其自身设置处理。

政策变更及联系

如需扩大 Google 权限、改变数据用途或向其他服务提供数据，应先更新此说明并取得用户相应同意。维护者为 TENSHINRAN。如有本工具相关问题，请通过 项目 Issues 联系维护者；Google 授权页也提供本应用的用户支持邮箱。

本工具对 Google API 数据的使用和传输遵守 Google API Services User Data Policy，包括适用的 Limited Use 要求。
